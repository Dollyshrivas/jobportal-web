# AI Job Portal

A modern, full-stack job portal application designed to streamline the hiring process for both job seekers and recruiters. The platform enables users to browse opportunities, submit applications, and receive AI-powered career assistance through an integrated Python chatbot.

The project demonstrates full-stack development skills, RESTful API design, database management, authentication, and AI integration.

---

## Overview

The AI Job Portal is built with a scalable architecture that separates the frontend, backend, and AI components. It focuses on creating a seamless recruitment experience while showcasing modern web development practices.

## Installation

### Clone the Repository

```bash
git clone https://github.com/Dollyshrivas/jobportal
```

### Navigate to the Project

```bash
cd jobportal
```

### Configure Environment Variables

Create a `.env` file inside the server directory.

```env
PORT=5000
DB_URI=YOUR_MONGODB_CONNECTION_STRING
COOKIE_SECRET="secret"
```

### Run the Backend

```bash
npm run dev
```
